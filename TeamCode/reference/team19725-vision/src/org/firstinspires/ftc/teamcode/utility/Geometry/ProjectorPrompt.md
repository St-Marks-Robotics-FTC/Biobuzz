In EulerAngle.java, implement a 3D attitude class based on Euler angles with three properties: roll, pitch, yaw, representing the rotation angles about the x, y, and z axes respectively, applied in ZYX order. Provide a frame-transform method transform(Vector3d vec) returning a Vector3d vector representing the coordinates in the transformed frame, and reform(Vector3d vec) returning a Vector3d vector representing the coordinates in the original (pre-transform) frame.
Then implement the Projector class per Plan.md, with one property EulerAngle Pose representing the current projector attitude, plus one property l0. Provide a function project(x_p, y_p, k) returning a Vector3d vector representing the absolute coordinates.
